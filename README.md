## 🎯 Course Philosophy

This course is for **Java developers** who want to build AI features that hold up inside a real application. You will work with the official **OpenAI Java SDK**, the **MCP Java SDK**, **LangChain4j**, **Spring AI 2.0** and **Google's Agent Development Kit (ADK)**.

> We do not start with a framework. The first part of the course is **plain Java**. You build conversation memory and store it in PostgreSQL over JDBC. You write vector search against pgvector, a RAG pipeline, a tool-calling loop and your own MCP server, all by hand. The frameworks come later, once you already know what they are doing for you.

Every session is live, so the code is written in front of you and your questions are answered while the problem is still on the screen.

## 🧱 Why This Course Starts Without a Framework

<table>
<tr><td>

Spring AI and LangChain4j both move fast. Spring AI went from 1.0 to 2.0 and now needs a new Spring Boot generation. LangChain4j still ships its agent and skills modules as beta. Knowing the underlying concepts is what lets you judge an upgrade and debug an issue.

So you write the loop yourself first:

`Message history` → `Vector query` → `Tool schema` → `Retry logic` → `MCP server` → **then the framework**

That shows up at work. You can read a release note and know whether it matters to your project. You can follow a stack trace into framework code instead of stopping at it. And you can say plainly in a design review whether a library is worth taking on.

</td></tr>
</table>

## 📂 Repository Structure

This repository holds **all the source code** taught class by class. Each folder is named by topic and class date, so you can follow along with the exact code from the session.

Inside a class folder, each project is a separate Maven project that you can open and run on its own:

```
agentic-ai-java-cohort/
├── 📁 First Java Program with AI 21-10-2026/
│   └── first-llm-call/                  # Plain Java: raw HttpClient, OpenAI Java SDK, LangChain4j
│       └── src/main/java/main/
│           ├── LaunchAiAPP.java         # First call with java.net.http.HttpClient (Responses API)
│           ├── LaunchOpenSDK.java       # Same call with the official OpenAI Java SDK
│           ├── LaunchLC4J.java          # Same call with LangChain4j's ChatModel
│           └── TeluskoSupport.java      # LangChain4j AI Service interface (preview)
│
├── 📁 Chat API Deep Dive Roles, Parameters and Token Usage 22-10-2026/
│   ├── first-llm-call-22-oct/           # Plain Java: OpenAI Java SDK + LangChain4j
│   │   └── src/main/java/main/
│   │       ├── LaunchAiAPP.java         # Raw HTTP call (recap)
│   │       ├── LaunchOpenSDK.java       # System / user / assistant roles; why the model "forgets"
│   │       ├── LaunchOpenSDK2.java      # temperature and maxCompletionTokens
│   │       ├── LaunchOpenSDK3Token.java # Reading prompt, completion and total token usage
│   │       ├── LaunchLC4J.java          # ChatRequest with temperature and maxOutputTokens
│   │       └── TeluskoSupport.java      # LangChain4j AI Service interface
│   │
│   └── llm-call-springai/               # The same topic in Spring AI 2.0 (Spring Boot app)
│       └── src/main/java/com/telusko/llm_call_springai/
│           ├── LlmCallSpringaiApplication.java
│           └── web/ChatController.java  # /api/ask, /api/chat, /api/metadata
│
├── 📁 Response Streaming in Java 26-10-2026/
│   ├── streamingcorejava/               # Plain Java: streaming with the OpenAI Java SDK
│   │   └── src/main/java/telusko/corejava/
│   │       ├── LaunchStremvsBlock.java              # Blocking vs streaming: time to first word
│   │       ├── LaunchChatCompletionStreamDemo.java  # Chat Completions streaming, chunk by chunk
│   │       └── LaunchResponseStream.java            # Responses API streaming + token usage on completion
│   │
│   └── llm-call-springai/               # Spring AI 2.0: maxCompletionTokens and finish reason
│       └── src/main/java/com/telusko/llm_call_springai/
│           ├── LlmCallSpringaiApplication.java
│           └── web/ChatController.java  # /api/ask, /api/chat, /api/metadata (+ finishReason)
│
├── 📄 .gitignore
└── 📄 README.md
```

| # | Class folder | What it covers |
|:--|:-------------|:---------------|
| 1 | `First Java Program with AI 21-10-2026` | The first AI call from Java, three ways: raw `HttpClient`, the OpenAI Java SDK and LangChain4j |
| 2 | `Chat API Deep Dive Roles, Parameters and Token Usage 22-10-2026` | Chat Completions, message roles, model parameters (temperature, max tokens) and token usage, in plain Java, LangChain4j and Spring AI |
| 3 | `Response Streaming in Java 26-10-2026` | Streaming responses with the OpenAI Java SDK (Chat Completions and Responses API), blocking vs streaming latency, token usage from the completed event, and `finishReason` with `maxCompletionTokens` in Spring AI |

> 📌 **A new folder is added after every class** as the course moves through memory, RAG, tool calling, MCP, agent design, LangChain4j, Spring AI and Google ADK.

## ⚡ Getting Started

> **Prerequisites:** Java 21+, Maven, an IDE (IntelliJ IDEA, Eclipse or STS) and an OpenAI API key set as `OPENAI_API_KEY` (see [API Keys & Environment](#-api-keys--environment)).

```bash
# 1. Clone the repository
git clone https://github.com/telusko-aliens/agentic-ai-java-cohort.git
cd agentic-ai-java-cohort

# 2. Move into the class you want to run
cd "Chat API Deep Dive Roles, Parameters and Token Usage 22-10-2026"
```

<details open>
<summary><b>☕ Core Java (OpenAI Java SDK + LangChain4j)</b></summary>

```bash
cd first-llm-call-22-oct
mvn compile exec:java -Dexec.mainClass="main.LaunchOpenSDK"
```

Swap the class name to run any other demo, for example `main.LaunchOpenSDK2`, `main.LaunchOpenSDK3Token` or `main.LaunchLC4J`.

</details>

<details>
<summary><b>🍃 Spring AI 2.0</b></summary>

```bash
cd llm-call-springai
./mvnw spring-boot:run        # Windows: mvnw.cmd spring-boot:run
```

Then call the endpoints from a browser or Postman:

```
http://localhost:8080/api/ask?message=What is Java
http://localhost:8080/api/chat?message=What is Spring Boot
http://localhost:8080/api/metadata?message=Explain dependency injection
```

`/api/metadata` returns the answer along with the model name and input, output and total token counts.

</details>

> 💡 Each project is self-contained with its own `pom.xml`. You can also import the folder into your IDE as a Maven project and run any class with a `main` method directly.

## 🔑 API Keys & Environment

Every project reads the key from the `OPENAI_API_KEY` environment variable, so **no keys are ever committed to this repository**.

```bash
# Windows (Command Prompt), then restart your IDE / terminal
setx OPENAI_API_KEY "sk-your-key-here"

# macOS / Linux
export OPENAI_API_KEY="sk-your-key-here"
```

- Get an OpenAI key from **https://platform.openai.com/api-keys**
- The Spring AI project picks it up through `spring.ai.openai.api-key=${OPENAI_API_KEY}`
- ⚠️ **Never** share or push your API key, and never hardcode it inside a `.java` or `.properties` file
